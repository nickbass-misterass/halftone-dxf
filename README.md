# Halftone DXF

Фото в сетку отверстий и DXF в миллиметрах. Программа для памятников, перфопанелей, декоративных экранов и ЧПУ: где темнее — отверстия крупнее, где светлее — мельче или пропуск.

![Скриншот](app.png)

## Возможности

- Сетка прямая или шахматная (ряды со сдвигом на полшага).
- Отверстия: кружки, квадраты, ромбы.
- Размеры в мм: стол, шаг сетки, мин. и макс. диаметр, минимальное расстояние между отверстиями (перемычка).
- Детализация, контраст, гамма, порог пропуска, инверсия.
- Живой предпросмотр: зум колесом мыши до x30, панорама перетаскиванием, двойной клик — сброс.
- Экспорт DXF: слой HOLES (отверстия), слой OUTLINE (контур стола).
- Тёмная тема с анимациями и настройкой прозрачности окна.

## Запуск

Готовый файл без установки — `Halftone DXF.exe` в разделе Releases (архив `Halftone.rar`).

Из исходников:

    pip install pillow ezdxf
    python halftone_dxf.py

Или двойной клик по файлу «Запустить программу.bat».

## Состав

- `halftone_dxf.py` — приложение
- `ui_kit.py` — виджеты оформления
- `make_icon.py` — генератор иконки
- `app.ico`, `app.png` — иконка
- `README.txt` — краткая инструкция

## Требования

Windows, Python 3.9+ (для запуска из исходников), библиотеки pillow и ezdxf.
